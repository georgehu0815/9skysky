arm-reach-v1

标定与末端到达

先建立坐标、软限位与安全触达，不夹取物品。

设计原型 / 未训练

材料

单臂、固定底板、标定靶点；不夹物品。

场景

TCP 前方可达球内抽取目标，先平面后立体；目标经 IK 与碰撞筛选。

动作

安全 home、转底座、肩肘接近、腕姿态对齐、保持、返回。

训练阶段

阻尼最小二乘 IK 教师 → BC/DAgger → PPO reach → 严格留出评估。

课堂重点

改关节零点 +3° 后观察误差，再恢复标定重新评估。

评估状态

建议门槛：位置 ≤5 mm 且可控工具轴角度 ≤5°，保持 1 s，12 s 内，无自碰/桌碰，≥95/100；结果 —。

建议门槛不是成绩；零动作、随机 actor 与交换目标均需作为负控制。
